# ClaimSafe working agreement

- Implement requested changes in this repository and verify the affected behaviour.
- Commit meaningful completed work locally on the current branch without asking for
  confirmation each time. The user has explicitly authorised this workflow.
- Leave GitHub pushes to the user. Do not push, create remote repositories, publish or
  change remote configuration unless the user explicitly requests it.
- Before committing, review the diff and stage only files belonging to the task. Preserve
  unrelated user changes. Never commit `.local/`, credentials, databases or `.venv/`.
- Use ordinary project filenames and clear commit messages. Do not create empty commits.
- Keep security decisions and actual verification results accurate. Do not claim that
  unperformed testing or deployment work is complete.
- At handoff, briefly state what changed, what was checked, the local commit identifier,
  and how to run or access the result when relevant.
