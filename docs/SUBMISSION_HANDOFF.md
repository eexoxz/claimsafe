
From the same repository terminal, you can import that certificate into your own Windows
user's trusted root store:

```powershell
Import-Certificate -FilePath .local\https\tls\pki\authorities\local\root.crt -CertStoreLocation Cert:\CurrentUser\Root
```

profile. Never import or share root.key. Restart the browser if needed, then verify that

uses a different CA; do not mix the two profiles. If trust still fails, stop and send the
